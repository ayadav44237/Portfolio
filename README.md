# Alok Yadav — Portfolio

A responsive, professional portfolio website built with **React** and **Vite**.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build for production

```bash
npm run build
npm run preview
```

## Resume PDF

To enable "Download Resume (PDF)", place your `Alok_latest_Resume.pdf` in the `public` folder. It’s already set up if you’ve copied it there.

## Customization

- **Content**: Edit the data in `src/components/` (Hero, About, Skills, Experience, Projects, Education, Contact).
- **Photo**: Replace `public/Alok.jpeg` to update the profile image.
- **Styling**: Global variables are in `src/index.css`; component styles are in each component’s `.css` file.
